/01 Developer Intent & Environment Setup

> Task Objective

Refactor an asynchronous JWT token validation race condition in a multi-tenant monorepo package (packages/auth), write missing unit tests, and update session refresh handling without breaking downstream services.

2. Environment Lock Model locked via /config to Sonnet 3.5 with Medium effort and a 1-hour TTL block.
