1. AST Repo-Map MCP

Context Reduction Server

Instead of letting the agent read every source file directly, integrate an open-source MCP Server that generates a lightweight repository map using Tree-sitter[cite: 1].

  • > Mechanism: Parses codebase into an AST containing only class names, function signatures, and exports[cite: 1].
  • > Impact: Reduces codebase indexing context from ~100,000 tokens down to ~5,000–10,000 tokens per scan[cite: 1].

> Context Comparison

Standard Output (100k Tokens) export const auth = (req, res) => {
  // 50 lines of logic...
}
MCP AST Output (5k Tokens) export const auth = (req, res) => void;
