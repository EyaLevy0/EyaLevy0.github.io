/01 Optimization Principles

> Principle A: Input Scoping

Never allow the model to read entire repositories when only a fraction of the code is relevant[cite: 1]. Use explicit directory ignore rules and symbol-level references[cite: 1].

> Principle B: Skeletal Representation

Pass structural interfaces, types, and function signatures (ASTs) rather than full implementation logic when explaining external dependencies[cite: 1].

> Principle C: Output Truncation

Force the model to return unified diffs, line-targeted patches, or specific function overrides instead of rewriting whole files[cite: 1].

> Principle D: Session Hygiene

Treat conversation context as volatile memory[cite: 1]. Regularly reset session history once a discrete sub-task is completed[cite: 1].
